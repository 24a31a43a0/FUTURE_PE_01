## 🧠 Prompt System Used

### System Prompt Template
```
You are an expert website copywriter specializing in local businesses. Your task is to generate compelling, conversion-focused website copy for a [BUSINESS_TYPE] named [BUSINESS_NAME] located in [CITY]. 

Follow this structure:
- Tone: [TONE] (e.g., warm, professional, energetic)
- Target audience: [AUDIENCE]
- Core value proposition: [USP]

Generate: Homepage hero, About section, Services section, and CTA section.
Keep language simple, persuasive, and action-oriented.
```

## 📋 Prompt Engineering Learnings

### What Made These Prompts Effective:
1. **Role assignment** – Telling the AI "You are an expert copywriter" improved output quality significantly
2. **Context layering** – Business name + location + tone + audience + USP gave targeted results
3. **Structured output request** – Asking for specific sections (Hero, About, Services, CTA) prevented generic responses
4. **Tone specification** – "warm and luxurious" vs "professional and trustworthy" produced noticeably different copy

### Prompt Iteration Example (Salon):
- **V1 (vague):** "Write website copy for a salon" → Generic, no local touch
- **V2 (better):** "Write copy for Sunshine Beauty Salon in Hyderabad" → Better but no USP focus
- **V3 (final):** Full structured prompt above → Specific, persuasive, conversion-focused ✅
